Легковесный Composer-шаблон (скелетон), разработанный для быстрой подготовки чистого окружения для установки *
*1С-Битрикс** с изоляцией публичной директории.

---

## 🎯 Основная задача и идея

Этот проект не содержит исходного кода CMS. Это минималистичный адаптер, который подготавливает рабочую область и
динамически скачивает официальные скрипты от 1С-Битрикс (`bitrixsetup.php`, `restore.php`, `bitrix_server_test.php`) во
время выполнения команды `composer create-project`.

### Ключевые особенности архитектуры:

* **Изоляция публичной директории**: Развертывание подготовлено под структуру, где корень веб-сервера указывает на папку
  `public/`. Это защищает служебные файлы (такие как папка `vendor/` и конфигурационные файлы) от прямого доступа из
  веб.
* **Выбор шагов**: Интерактивная заглушка по пути `public/index.html` (корень сайта), который помогает выбрать следующий
  шаг установки.
* **Минимум зависимостей (Zero Bloat)**: Намеренно не используются сторонние пакеты Composer (компоненты Symfony,
  библиотеки PSR, ORM). Проект содержит только проверку требований к PHP и расширениям.
* **Динамическая загрузка**: Весь вендорский софт скачивается во время установки через хуки `post-create-project-cmd`.

## 🚀 Быстрый старт

Для создания нового проекта на Битриксе выполните стандартную команду Composer:

```bash
composer create-project crasivo/bitrix-installer my-bitrix-site
```

### Что происходит при установке:

1. Composer проверяет совместимость вашего окружения (версию PHP и наличие необходимых расширений).
2. Создается изолированная папка `public/` (DOCUMENT_ROOT).
3. Копируется интерактивная заглушка `index.html` в папку `public/`.
4. Скачиваются актуальные версии официальных скриптов в папку `public/`:

* `bitrixsetup.php` -> скрипт пошаговой установки CMS.
* `restore.php` -> скрипт восстановления проекта из резервной копии.
* `bitrix_server_test.php` -> утилита тестирования сервера на соответствие требованиям.
* `bitrixsetup.debug` и `restore.debug` -> дебаг-файлы для авторизации скриптов.
* `phpinfo.php` и `robots.txt` -> вспомогательные конфигурационные файлы.

После завершения установки настройте корень веб-сервера `DOCUMENT_ROOT` на папку `public/` и откройте ваш сайт в
браузере, чтобы выбрать нужное действие.
